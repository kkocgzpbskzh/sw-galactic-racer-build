## Overview

STAR WARS: Galactic Racer Build is a companion optimizer for the classic Star Wars Episode I Racer game, calculating optimal part upgrade allocation across all 21 racers and their individual stat equations. Enter available credits and target racers to receive the maximum-speed build configuration that fits within budget.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **STAR WARS Galactic Racer Build** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Budget Optimizer** | Calculates maximum performance build within a specified credit budget |
| **All 21 Racers** | Complete stat equations and upgrade tables for all playable racers |
| **Speed Breakdown** | Shows top speed, acceleration, and traction contribution per part |
| **Track Recommender** | Suggests racer builds optimized for specific circuit environments |
